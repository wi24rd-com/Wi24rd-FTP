# Support

Wi24rd FTP is maintained by one person in spare time. There is no promised
response time and no individual support.

- **How do I use it?** The [README](README.md) covers what the buttons do,
  installation and the security notes. A [Danish version](README.da.md) is there too.
- **Something failed.** Look in `%ProgramData%\Wi24rdFTP\log\`: every call to the
  backend is written there.
- **The recipient cannot connect.** Check that the port is forwarded on your
  router, and, for FTP, that the passive range 50000-50100 is open as well.
- **Something is broken in the program.** Open an issue with the bug form.
- **A security problem.** Report it privately; see [SECURITY.md](SECURITY.md).
